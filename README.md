# Вкус Мира

Сайт кафе «Вкус Мира» с заказами онлайн и админ-панелью.

- **Сайт** (`index.html`, `menu-data.js`, `img/`): меню, корзина, оформление заказа. Заказ сохраняется в базу и отправляется в WhatsApp.
- **Админ-панель** (`/admin/`): вход по паролю, статистика и графики, заказы в реальном времени, история с поиском, управление меню и фото.
- **Сервер** (`server/server.js`): Node.js без внешних библиотек, база SQLite (`data/cafe.db`), загруженные фото в `data/uploads/`.

## Запуск

Нужен Node.js 22.13 или новее.

```bash
ADMIN_PASSWORD='придумайте-пароль' npm start
```

Сайт: http://localhost:3000, админ-панель: http://localhost:3000/admin/

При первом запуске сервер создаёт базу и заполняет меню из `menu-data.js`. Если `ADMIN_PASSWORD` не задан, сервер придумает пароль сам, выведет его в журнал и сохранит в `data/admin-password.txt`. Пароль можно сменить в разделе «Настройки».

## Настройки (переменные окружения)

| Переменная | Что задаёт | По умолчанию |
|---|---|---|
| `PORT` | порт сервера | `3000` |
| `DATA_DIR` | папка с базой и фото | `./data` |
| `ADMIN_PASSWORD` | пароль администратора при первом запуске | создаётся автоматически |
| `TZ_OFFSET_MIN` | часовой пояс для статистики, в минутах | `360` (Бишкек, UTC+6) |
| `TRUST_PROXY` | `1`, если сервер стоит за прокси или хостингом | — |
| `COOKIE_SECURE` | `1`, чтобы вход работал только по HTTPS | включается сам при HTTPS за прокси |

Номер WhatsApp, адрес и часы работы задаются в блоке `CONFIG` в `index.html`.

## Размещение в интернете

Папку `data/` нужно хранить на постоянном диске: в ней все заказы и фото. Резервная копия — это копия этой папки.

Пример с Docker:

```bash
docker build -t vkus-mira .
docker run -d -p 3000:3000 -v vkus-mira-data:/data -e ADMIN_PASSWORD='пароль' vkus-mira
```

Подойдёт любой хостинг с Node.js или Docker и постоянным диском (VPS, Railway с томом, Render с диском и т. п.). Сайт должен открываться по HTTPS.

## Как считается статистика

- «Заказов» — все заказы, кроме отменённых.
- «Выручка» — только оплаченные и не отменённые заказы. Заказ становится оплаченным сам при статусе «Доставлен», либо отмечается вручную переключателем «Оплачен».
- «Сегодня», «7 дней» и «30 дней» считаются по местному времени (`TZ_OFFSET_MIN`).
