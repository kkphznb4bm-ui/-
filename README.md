# Вкус Мира

Сайт кафе «Вкус Мира»: меню, корзина, заказ с отправкой в WhatsApp и админ-панель (`admin/index.html`, ссылка «Вход для администратора» внизу сайта).

## Три режима работы

Сайт сам выбирает режим при открытии:

| Режим | Когда включается | Где хранятся заказы и меню |
|---|---|---|
| **Firebase** | в `firebase-config.js` вставлены настройки проекта | в бесплатной базе Google Firestore, общей для всех гостей и администратора |
| **Сервер** | сайт открыт через `server/server.js` | в SQLite на своём сервере (`data/cafe.db`) |
| **Демо** | во всех остальных случаях (например, страница на claude.ai) | только в этом браузере; вход: логин `admin`, пароль `vkusmira` |

## Подключение Firebase (бесплатно, тариф Spark)

1. Откройте https://console.firebase.google.com под Google-аккаунтом кафе → **Добавить проект** → название `vkus-mira` → Google Analytics можно выключить → **Создать**.
2. **Build → Firestore Database → Create database** → расположение `eur3 (Europe)` → **Start in production mode** → **Create**.
3. **Build → Authentication → Get started → Email/Password** → включить → **Save**. Затем вкладка **Users → Add user**: почта и пароль администратора.
4. **Firestore Database → Rules**: вставьте содержимое файла `firestore.rules`, заменив `ADMIN_EMAIL` на почту администратора из шага 3 → **Publish**.
5. Шестерёнка → **Project settings → General → Your apps → значок `</>`** → название `site` → **Register app**. Скопируйте блок `firebaseConfig`.
6. Вставьте этот блок в `firebase-config.js` вместо `null` и добавьте строку `adminEmail: "почта администратора"` (пример в самом файле).

При первом входе администратора меню автоматически загрузится в базу из `menu-data.js`.

### Размещение сайта бесплатно

Подходит любой статический хостинг: файлы сайта лежат в корне репозитория, сборка не нужна.

- **Cloudflare Pages**: Workers & Pages → Create → Pages → Connect to Git → выбрать репозиторий и ветку → Build command пусто, Build output directory `/` → Deploy. Работает и с закрытым репозиторием.
- **Firebase Hosting**: `npx firebase-tools deploy --only hosting,firestore:rules` (настройки уже в `firebase.json`).
- **GitHub Pages**: Settings → Pages → Deploy from a branch (для открытого репозитория).

### Что важно знать о бесплатном тарифе

- Лимиты Firestore: 50 000 чтений и 20 000 записей в день — для кафе с запасом.
- Фото, загруженные из админ-панели, уменьшаются до 700 px и хранятся прямо в базе (отдельное хранилище файлов на бесплатном тарифе недоступно).
- Правила базы проверяют вид заказа и не дают гостям читать заказы или менять меню. Пересчитать сумму на стороне Google без платных функций нельзя, поэтому администратор проверяет состав и сумму при принятии заказа.

## Свой сервер (по желанию)

Нужен Node.js 22.13+: `ADMIN_PASSWORD='пароль' npm start`, затем http://localhost:3000 и http://localhost:3000/admin/. Подробности о переменных окружения — в начале `server/server.js`. Для Docker: `docker build -t vkus-mira . && docker run -d -p 3000:3000 -v vkus-mira-data:/data -e ADMIN_PASSWORD='пароль' vkus-mira`.

## Как считается статистика

- «Заказов» — все заказы, кроме отменённых.
- «Выручка» — только оплаченные и не отменённые заказы. Заказ становится оплаченным сам при статусе «Доставлен» или вручную переключателем «Оплачен».
- «Сегодня», «7 дней», «30 дней» — по времени Бишкека (UTC+6).
