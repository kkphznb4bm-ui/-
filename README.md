# ХАВАЮ! How Are You?

Сайт-меню с главным экраном, хитами, спецпредложениями, фильтрами по категориям, корзиной, оплатой по QR и заказом через WhatsApp. Откройте `index.html` в браузере.

- Все настройки (WhatsApp, телефон, Instagram, адрес, часы работы, QR для оплаты, хиты, отзывы) — в блоке `CONFIG` в начале `<script>` в `index.html`.
- Меню и цены — массивы `CATS` и `MENU` там же.
- Фото — папка `img/`.
- Сайт Терияки — в папке `teriyaki/`.
